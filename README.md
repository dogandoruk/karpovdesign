**Live Architectural Portfolio Concept:** [https://dogandoruk.github.io/karpovdesign/](https://dogandoruk.github.io/karpovdesign/)

## Project Overview
This repository hosts the interactive architectural portfolio website concept for **Karpov Design LLC**, built around an unfolding homepage journey across 5 core typologies.

### Key Features
1. **Full-Bleed 100vh Hero Banner:** Left-aligned KAD stroke monogram (transparent vector geometry).
2. **5-Column Typology Accordion:** Single-Family, Multi-Family, Commercial, Art & Objects, School / Educational with hover-dim overlays and zero-reload accordion focus.
3. **Dynamic Architectural Album Component:** Interactive showcase with featured viewport and 5-thumbnail carousel strip (Concept Sketch → Public Space → Plan → BIM → Exterior).
4. **4 Core Architectural Views:**
   - Homepage (The spatial journey)
   - Category Archive (Typology deep-dive with NCGS § 83A Collaborations Switch)
   - Project Detail (Long-form case study with P01-P05 Process Strip)
   - Academy (Revit BIM workshops, video tutorials & study guides)
